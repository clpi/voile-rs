# voile-rs

Dependently-typed row-polymorphic programming language, evolved from minitt-rs

Written mainly in Rust, HTML, Shell, Batchfile.

## Contents

- `CHANGELOG.md` — a Markdown file
- `Cargo.toml` — the Rust crate manifest
- `LICENSE` — the license
- `rustdoc` — directory
- `rustfmt.toml` — a TOML configuration file
- `samples` — directory
- `src` — source code
- `voile-util` — directory

## Build and run

A Rust crate or workspace; its manifest is `Cargo.toml`, so the usual Cargo commands (`cargo build`, `cargo test`) apply.
